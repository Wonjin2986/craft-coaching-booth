AI 기반 학습자주도 수업 연구회 · 2026. 11. 21. 코칭 아카데미 성과 나눔의 날

- [체험 시작](https://wonjin2986.github.io/craft-coaching-booth/)
- [진행자 안내](https://wonjin2986.github.io/craft-coaching-booth/진행자_안내.html)

## 체험 흐름
1. C · Context — 필요 탐색
2. R · Requirements — 자료 설계
3. A · AI creation — AI 제작
4. F · Feedback — 검토·보완
5. T · Transfer — 적용·성찰

코칭 질문에 답해 제작 요청문을 만들고, 외부 AI 도구에서 자료를 제작·수정한 뒤 처음 정한 목표로 검토합니다. 마지막에 단계별 제작 기록을 저장합니다. 연구회가 제안한 체험 과정이며, 교육 효과가 검증된 교수설계 모형을 뜻하지 않습니다.

## 작동 범위와 입력 보관
- 별도 서버나 AI API 없이 작동하는 HTML·CSS·JavaScript입니다.
- 실시간 AI 채팅이 아니라 미리 설계한 질문을 제공합니다.
- 질문에 쓴 답은 현재 브라우저 탭의 sessionStorage에 임시 보관되며 이 사이트의 서버로 전송되지 않습니다.
- '새 참여자' 버튼은 이 화면의 입력만 지웁니다. 마이클의 대화·문서와 PC 다운로드 파일은 별도로 정리합니다.
- 마이클에서 실제 생성·편집하려면 사용할 수 있는 계정이 필요합니다. 계정·비밀번호는 이 저장소에 포함하지 않습니다.
- 학습지 경로는 본문 제작과 AI 한글 에디터 수정을, PPT 경로는 슬라이드 원고와 구성안 제작을 안내합니다.

## 게시 및 수정
GitHub Pages는 main 브랜치의 루트 폴더에서 배포합니다. index.html 또는 진행자_안내.html을 수정해 main에 반영하면 같은 웹 주소가 갱신됩니다. 배포 반영에는 시간이 걸릴 수 있습니다.

공개 파일은 index.html, 진행자_안내.html, 이 안내와 .nojekyll입니다. 참가자의 기록·운영 계정·비밀번호·개인 자료는 커밋하지 않습니다.
